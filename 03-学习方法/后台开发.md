# 后台开发工程师

## 技术栈

### 编程语言

- **Go**: 主要语言，适合高并发
- **Python**: 脚本和工具开发
- **Java**: 企业级应用

### 数据库

#### SQL 数据库

- MySQL: 关系型数据库首选
- PostgreSQL: 功能更强大

#### NoSQL 数据库

- MongoDB: 文档型数据库
- Redis: 缓存和 KV 存储

### 框架

- Go: Gin、Echo
- Python: FastAPI、Django

## 核心技能

1. **编程基础**: 数据结构、算法、设计模式
2. **数据库**: SQL 优化、索引、事务
3. **网络**: TCP/IP、HTTP、RPC
4. **Linux**: Shell、系统运维
5. **分布式**: 微服务、负载均衡、高可用

## 学习建议

### 必读书籍

- 《Unix编程艺术》
- 《Effective Go》
- 《高性能MySQL》
- 《Redis设计与实现》

### 实践项目

- 博客系统
- API 网关
- 爬虫系统
- 即时通讯
