# 提升学习方法，告别低效勤奋

## 时代背景

VUCA 时代特征：
- **V**olatility（易变性）
- **U**ncertainty（不确定性）
- **C**omplexity（复杂性）
- **A**mbiguity（模糊性）

BANI 时代特征：
- **B**rittle（脆弱的）
- **A**nxious（焦虑的）
- **N**on-linear（非线性的）
- **I**ncomprehensible（难以理解的）

## 目标设定

### SMART 原则

- **S**pecific（具体的）
- **M**easurable（可衡量的）
- **A**chievable（可实现的）
- **R**elevant（相关的）
- **T**ime-bound（有时限的）

### 示例

❌ "我要学好编程"
✅ "3个月内完成《算法竞赛入门经典》，每天学习2小时，完成200道算法题"

## 学习材料选取

### 选书原则

1. **经典教材**: 经得起时间检验的书
2. **适合水平**: 略高于当前水平
3. **实践导向**: 有配套练习

### 推荐资源

- 视频教程：Bilibili、YouTube
- 在线课程：Coursera、慕课
- 技术博客：官方文档、优质技术博客

## 高效阅读技巧

### 略读法

1. 看目录和章节标题
2. 看每章开头和结尾
3. 跳读重点章节

### 精读法

1. 带着问题阅读
2. 做笔记和批注
3. 实践和复盘

### 康奈尔笔记法

```
+------------------+--------+
|                  |  提示   |
|     主栏         |（线索） |
|                  |--------+
|                  |  总结   |
+------------------+--------+
```

## 信息处理

### 费曼学习法

1. 选择一个概念
2. 想象要教给一个小白
3. 遇到卡壳就回去学习
4. 简化语言

### 间隔重复

利用艾宾浩斯遗忘曲线，在合适的时间点复习：

| 时间点 | 复习强度 |
|--------|----------|
| 20分钟后 | 复习 |
| 1小时后 | 复习 |
| 1天后 | 复习 |
| 1周后 | 复习 |
| 1个月后 | 复习 |
